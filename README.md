# 摊友称重计价助手 (微信小程序)

> 专为废品回收站、菜市场摆摊、果蔬海鲜批发等线下称重交易场景量身打造的**极速称重计价与记账神器**。

---

## 🌟 核心特色与功能

### 1. ⚡ 纯离线零延迟语音播报 & 物理微震动
- **离线音频包**：内置本地高品质自然人声音频，无需依赖任何外网 TTS 接口，户外弱网、断网秒级即点即播。
- **智能金额拼读**：结算时自动按中文语法拼读总额（如：`125.50` 依次播报：`总共收废品 一百二十五元五角`）。
- **物理震动反馈**：每次按键伴随 `wx.vibrateShort` 物理轻微震动，强光下不看屏幕也能盲打防误触。

### 2. ⚖️ 智能去皮重 (Tare / 扣箱扣车)
- **行业刚需痛点**：现场带框、带桶、带推车称重时，一键快捷扣除皮重。
- **快捷胶囊与自定义**：支持 `净重(0)`、`1斤`、`2斤`、`3斤`、`5斤` 及任意自定义数值。
- **算式清晰分明**：界面大字清晰显示 `净重`，附小字 `(毛重 - 皮重)`，杜绝交易纠纷。

### 3. 🪙 人情世故：整单抹零与折价调整
- **灵活让利**：一键切换 `原价`、`抹分 (如128.45→128.40)`、`抹角到元 (如128.45→128.00)`、`凑整 (四舍五入)`、`自定义改实付`。
- **账实相符**：结算与播报严格按照实付金额执行，账本清晰记录让利金额。

### 4. 🧾 电子回收结算小票 (Canvas 2D 超清绘制)
- **权威凭证**：自动生成正规商用收据风格长图，印有店名、电话、单号、明细、净重/皮重、原价与抹零让利、大写金额。
- **防伪鲜章**：右上角加盖“已结算”倾斜仿真印章，底部附带小程序溯源码与锯齿撕纸效果。
- **微信长按分享**：一键保存到系统相册或直接发送给微信好友。

### 5. 📊 今日日结战报 & 一键微信对账
- **分类统计汇总**：日结卡片直观汇总今日每个品类的总收量（斤/公斤）、总金额、均价与单数。
- **一键复制发群**：点击一键生成排版工整的日结战报文本，直接粘贴到微信群向合伙人或老板报账。

### 6. 💳 老板收款码快捷出示
- 首页顶部常驻收款码入口，结算后可一键弹出微信/支付宝收款码大图，无需频繁退小程序切相册。

### 7. 👥 多顾客排队并行记账
- 支持 3 位或更多顾客同时排队挂单，点击标签自由切换，多人称重互不干扰。

---

## 🛠️ 技术栈
- 微信小程序原生框架（WXML / WXSS / JavaScript）
- 离线音频架构：`wx.createInnerAudioContext` 单例复用与队列管理
- 绘图引擎：Canvas 2D 离屏超清渲染
- 数据存储：本地 Storage 离线模式 + 微信云开发 / Supabase 双模容灾
